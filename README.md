# Supriya's Portfolio — Sample-Inspired Design

Built using HTML, CSS, and vanilla JavaScript only.

## Includes
- Warm white, coral, and editorial serif visual style inspired by the supplied reference
- Hero section, project cards, skill chips, About, and Contact
- Responsive mobile navigation
- Project category filters
- Expandable project details
- Client-side form validation (does not send messages)

## Before submission
- Replace sample project concepts with your own actual projects and learning notes.
- Replace the sample portrait with your own image if you want; update the image URL in `index.html`.
- Add your real email/GitHub link if you want them shown.
- Upload all files to a public GitHub repository.
- Enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
- Test the live link on mobile and desktop.
